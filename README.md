# Aethera Engine - Telegram Bot

نظام إدارة ومتابعة الأداء الرقمي الخاص بمشروع **Aethera**. هذا البوت مصمم لتقديم تحليلات لحظية، وتوفير أدوات تفاعلية للمستخدمين داخل مجتمع تليجرام.

## 🚀 المميزات
* **الترحيب التلقائي:** استقبال فوري للأعضاء الجدد مع توجيههم للقنوات الرسمية.
* **مؤشر السوق:** عرض بيانات لحظية عن عملة AETH (السيولة والسعر).
* **التفاعل:** نظام أزرار تفاعلية لسهولة التنقل داخل النظام.
* **الأمان:** مبني بمعايير حماية تمنع تسريب بيانات الاعتماد.

## 🛠 المتطلبات
* Node.js (v16+)
* Telegram Bot Token (يتم الحصول عليه من BotFather)
